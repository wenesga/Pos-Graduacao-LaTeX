# Pós-Graduação em LaTeX

Atividades da pós-graduação escritas em LaTeX.

## Conteúdo

- **Instalacao de Sistemas Fotovoltaicos**
  Resumo em slides (Beamer) dos conteúdos da disciplina Instalação de Sistemas Fotovoltaicos (IFTO).
  O arquivo `.tex` é o código-fonte e o PDF é a apresentação final.

## Como compilar

```bash
pdflatex resumo_instalacao_sfv.tex
```
